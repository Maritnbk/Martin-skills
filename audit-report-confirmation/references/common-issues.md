# 常见问题模式汇总

本文件收集了审计报告核对实践中发现的真实文本和数据问题，按类别组织。执行文本核对时逐一对照检查。

## ⚠️ 核对过程自身的问题

| 问题 | 表现 | 正确做法 |
|------|------|---------|
| **跳过核对项** | "这个科目没有数据，没检查" | 仍须列示，标记"➖ 无相关内容" |
| **合并检查项** | "资产负债表各项都核了"（未逐项列示） | 每个公式/合计行为一个独立检查项 |
| **默认通过** | 核对结果表中某行留空 | 每行必须标记 ✅ / ❌ / ➖ |
| **选择性核对** | 只核对了有数据的项目，跳过空白科目 | 即使为空也列示并标记 |

## 一、缺字

| 错误原文 | 应为 | 说明 |
|---------|------|------|
| 政府拨情况 | 政府拨款情况 | 缺"款" |
| 未政府补助收入 | 未收到政府补助收入 | 缺"收到" |
| 所得费收入 | 所得税费用 | 缺"税" |
| 银行款 | 银行存款 | 缺"存" |
| 计入当损益 | 计入当期损益 | 缺"期" |
| 拨付所属位资金 | 拨付所属单位资金 | 缺"单" |
| 交增值税 | 应交增值税 | 缺"应" |
| 公司名称中缺字 | ××股份限公司 | 缺"有" |

**检查技巧：** 重点关注"的""了""款""收""费""税""期""应""有"这些高频字的缺失。

## 二、错字

| 错误原文 | 应为 | 说明 |
|---------|------|------|
| 认证严格执行 | 认真严格执行 | 认证→认真，音近 |
| 关与 | 关于 | 关与→关于，音近 |
| 令一方面 | 另一方面 | 令→另，音近 |
| 既使 | 即使 | 既→即，音近 |
| 做为 | 作为 | 做→作，形近/音近 |
| 截止目前 | 截至目前 | 截止→截至，用词不当 |
| 其他延递支出 | 其他递延支出 | 延递→递延，颠倒 |
| 按排 | 安排 | 按→安，音近 |
| 在次 | 再次 | 在→再，音近 |
| 陝西（繁体） | 陕西（简体） | 繁体未转为简体 |

## 三、标点符号问题

| 问题 | 示例 | 正确写法 |
|------|------|---------|
| 重复句号 | "。。" | "。" |
| 英文标点混入 | 中文内容用了英文句号"." | 中文句号"。" |
| 括号不配对 | 中文内容用了英文括号")" | 中文括号"）" |
| 书名号间缺标点 | 《章程》《财务制度》 | 《章程》《财务制度》（可加顿号） |
| 引号不配对 | 前引号和后引号数量不一致 | 成对使用 |

## 四、数字与格式问题

| 问题 | 错误示例 | 正确示例 |
|------|---------|---------|
| 数据后缺"元" | "管理费用530,831.78" | "管理费用530,831.78元" |
| 逗号位置错误 | "190,0000" 或 "81,72,962.25" | "1,900,000" |
| 年度格式不一致 | "2024年"和"24年"混用 | 统一用"2024年" |
| 多余空格 | "收入合计  1,000,000" | "收入合计 1,000,000" |
| 金额单位不一致 | 部分用"元"，部分用"万元" | 统一单位 |
| 负号格式不一致 | "-100"和"（100）"混用 | 统一格式 |

## 五、表述不通顺

| 问题 | 示例 |
|------|------|
| 缺主语 | "经审计，认为财务报表公允反映了..."（缺"我们"或"注册会计师"） |
| 动宾不搭配 | "进行了制度的完善和修订了流程" |
| 语序混乱 | 长句语序不当 |
| 赘余重复 | "报告期内，报告期内，协会共完成..." |
| 模板残留 | 未替换的占位符如"【协会名称】"等 |
| 前后矛盾 | 前文说"无保留意见"，后文说"保留意见" |

## 六、数据常见陷阱

| 陷阱 | 说明 | 处理方式 |
|------|------|---------|
| 浮点数精度 | `5102.910000000001` | 四舍五入到两位小数 |
| 公式计算误差 | 合计列是 SUM 公式，可能有舍入误差 | 手动重算验证 |
| 千分位逗号 | `1,775,477.94` | 去掉逗号做数值比较 |
| 合并单元格 | 在 Markdown 中可能只出现一次值 | 注意表格行数 |
| 空值处理 | 单元格为空或显示为"-" | 按 0 处理 |
| 多层表头 | 主表头+子表头结构 | 逐列对齐，不要跳列 |
