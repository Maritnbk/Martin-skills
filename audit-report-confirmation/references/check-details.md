## 核对约束

> ⚠️ **以下检查清单中的每一条都必须执行并记录结果，不得跳过。**
>
> 如果被核对报告中不存在某科目或某表格（如无短期投资、无固定资产），核对结果中**仍须保留该检查项**，在结果中标记为"➖ 无相关内容"，并在备注注明"被审计单位无此业务"。
>
> **不得以"大概没问题""看起来一样""之前核过"为由跳过任何检查项。**

## 核对b：财务报表内部勾稽

### 操作步骤

#### Step 1：提取数值

从 MinerU 转换后的 Markdown 中定位资产负债表、利润表、现金流量表的数值。

#### Step 2：逐项加总验证

对每个合计项，手动将各明细数值加总，与报表中的合计行进行比对。

**关键原则：** 不使用报表自身的合计行作为正确值。独立计算后比较。

#### 2.1 资产负债表

| 验证项 | 公式 | 期末 | 期初 |
|--------|------|:----:|:----:|
| 存货 | 原材料+在产品+库存商品+周转材料 | □ | □ |
| 流动资产合计 | 货币资金+短期投资+应收票据+应收账款+预付账款+应收股利+应收利息+其他应收款+存货+其他流动资产 | □ | □ |
| 固定资产账面价值 | 固定资产原值-累计折旧 | □ | □ |
| 非流动资产合计 | 长期债权投资+长期股权投资+固定资产账面价值+在建工程+工程物资+固定资产清理+生产性生物资产+无形资产+开发支出+长期待摊费用+其他非流动资产 | □ | □ |
| 资产总计 | 流动资产合计+非流动资产合计 | □ | □ |
| 流动负债合计 | 短期借款+应付票据+应付账款+预收账款+应付职工薪酬+应交税费+应付利息+应付利润+其他应付款+其他流动负债 | □ | □ |
| 非流动负债合计 | 长期借款+长期应付款+递延收益+其他非流动负债 | □ | □ |
| 所有者权益合计 | 实收资本+资本公积+盈余公积+未分配利润 | □ | □ |

#### 2.2 利润表

| 验证项 | 公式 | 本年累计 | 上年累计 |
|--------|------|:--------:|:--------:|

| 利润总额 | 营业利润+营业外收入-营业外支出 | □ | □ |
| 净利润 | 利润总额-所得税费用 | □ | □ |

|--------|------|:--------:|:--------:|

## 核对d：附注表格内部数据核对

### 通用原则

对每个附注表格，逐项重算明细之和，然后与表格中的合计行比较。

**不直接引用合计行，所有合计行必须独立重算。**

### 各表格类型核对方法

#### 账龄表（应收/应付/其他应收/其他应付等）

```
各段账龄期末余额之和 = 合计期末余额
各段账龄期初余额之和 = 合计期初余额
```

账龄段通常为：1年以内、1-2年、2-3年、3年以上。

#### 前五名客户/供应商明细表

```
各客户金额之和 = 合计
各客户余额比例 = 各客户期末余额 / 对应科目期末余额 × 100%
```

**常见问题：** 占比之和偏离100%、合计金额与明细之和不符。

#### 固定资产及累计折旧表

**双重验证：**

验证一（变化勾稽）：
```
各项目期初余额 + 本期增加 - 本期减少 = 期末余额
```

验证二（净值勾稽）：
```
账面原值 - 累计折旧 - 减值准备 = 账面价值
```

分别对每个资产类别（机器设备、运输设备、电子设备等）验证，再验证明细之和=合计。

#### 长期待摊费用表

```
各项目之和 = 合计
各项目期初余额 + 本期增加 - 本期减少 = 期末余额
```

#### 应付职工薪酬表

```
各项目之和 = 合计
各项目期初余额 + 本期增加 - 本期减少 = 期末余额
```

薪酬项目通常包括：工资、奖金、社保、住房公积金、工会经费、职工教育经费等。

#### 实收资本表

```
各股东期初余额之和 = 合计的期初余额
各股东期末余额之和 = 合计的期末余额
各股东本期增加之和 = 合计的本期增加
各股东本期减少之和 = 合计的本期减少
各股东期初余额 + 本期增加 - 本期减少 = 期末余额
```

#### 只有期末余额、期初余额的表格

```
各项目期末余额之和 = 合计的期末余额
各项目期初余额之和 = 合计的期初余额
```

*适用于：其他应付款明细、短期借款明细、专项应付款明细等*

#### 只有本期发生额、上期发生额的表格

```
各项目本期发生额之和 = 合计的本期发生额
各项目上期发生额之和 = 合计的上期发生额
```

*适用于：营业收入明细、营业成本明细、销售费用明细、管理费用明细等*

## 核对e：报表与附注交叉核对

将资产负债表、利润表的每个行项目，与对应的附注明细表进行核对：

```
资产负债表的货币资金期末余额 = 附注"货币资金"明细表的合计期末余额
资产负债表的应收账款期末余额 = 附注"应收账款"明细表的合计期末余额
利润表的营业收入本年累计数 = 附注"营业收入"明细表的合计本期发生额
...（以此类推，逐项核对）
```

**必须覆盖所有在报表中出现、且有对应附注的科目。**

## 多年度衔接核对

### 跨年数据衔接

对每对相邻年份（N 和 N+1），逐项验证：

| 科目 | N年期末 = N+1年期初 | 结果 |
|------|:-------------------:|:----:|
| 货币资金 | | |
| 应收账款 | | |
| 存货 | | |
| 固定资产账面价值 | | |
| 应付账款 | | |
| 应交税费 | | |
| 实收资本 | | |
| 未分配利润 | | |
| 资产总计 | | |

### 利润表/现金流量表跨年

```
N年利润表本年累计数 = N+1年利润表上年累计数
N年现金流量表本年累计发生额 = N+1年现金流量表上年累计发生额
```

### 附注跨年

```
N年附注期末余额 = N+1年附注期初余额
N年附注本期发生额 = N+1年附注上期发生额
```

## 问题传播核对

### 步骤

1. 汇总各年度全部发现的问题
2. 识别传播模式（全部年份存在 / 首次出现后传播 / 早期存在后期修正 / 被引用传播）
3. 检查被引用传播：N年的错误数据是否被N+1年作为"上期数/期初数"引用
4. 记录传播检查结果

### 传播模式判断

| 传播模式 | 判断标准 | 动作 |
|---------|---------|------|
| 全部年份存在 | 同一问题在全部年份出现 | 统一修正模板源 |
| 首次出现后传播 | 在 Year N 首次出现，后续年度也有 | 联动修正 |
| 早期存在，后期修正 | 早期年份有，最新年份已修正 | 回溯修正早期 |
| 仅单年度存在 | 只有一个年份有 | 单独修正 |
| 被引用传播 | N年错误数据被N+1年引用 | 修正后检查所有引用处 |
